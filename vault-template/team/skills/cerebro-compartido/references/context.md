# Retomar trabajo

1. Resolver `BRAIN_ROOT` y `PARTICIPANT_ID` sin adivinar.
2. Leer `.brain/conventions.md`.
3. Si hay proyecto explícito, leer `team/projects/<project>/INDEX.md` y después `TLDR.md` sólo si hace falta el resumen humano.
4. Leer `team/decisions/INDEX.md` y abrir únicamente las decisiones relacionadas.
5. Leer `each_one/<participant-id>/INDEX.md` y sólo los enlaces necesarios.
6. Resumir qué está vigente, próximo paso y bloqueos; distinguir hechos de inferencias.
