# Skills del equipo

Las skills aprobadas por el equipo viven aquí. `setup-hub` copia la skill `cerebro-compartido` del kit al crear el cerebro, y los instaladores (`infra/<os>/install-skills`) enlazan este directorio hacia `~/.codex/skills/`, `~/.claude/skills/` y `~/.agents/skills/` en cada máquina.

Para agregar una skill compartida, crear `<nombre>/SKILL.md` y avisar al equipo para que reinstale.
