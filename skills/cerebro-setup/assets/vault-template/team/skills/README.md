# Skills del equipo

Las skills aprobadas por el equipo viven aquí. Al crear el cerebro, la skill `cerebro-setup` copia `cerebro-leer` y `cerebro-cierre` del plugin, y los instaladores (`install-skills.sh` / `install-skills.ps1` en los assets de `cerebro-setup`) enlazan este directorio hacia `~/.codex/skills/`, `~/.claude/skills/` y `~/.agents/skills/` en cada máquina.

Para agregar una skill compartida, crear `<nombre>/SKILL.md` y avisar al equipo para que reinstale.
