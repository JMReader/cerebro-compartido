# SharedBrain — vault del equipo

Este directorio es el vault Obsidian sincronizado entre las computadoras del equipo.

## Entrada rápida

- Contexto y decisiones comunes: `team/`
- Trabajo de cada persona/agente: `each_one/<participant-id>/`
- Configuración y reglas: `.brain/`
- Plantillas: `_templates/`

Antes de escribir, cada agente debe tener definidos `BRAIN_ROOT` y `PARTICIPANT_ID`. Las skills `cerebro-leer` y `cerebro-cierre` aplican el contrato de lectura y escritura.
